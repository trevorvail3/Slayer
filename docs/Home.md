# ⚔️ Slayer — Design Vault

A fully 3D, **first-person fantasy looter** — "Destiny 2 with swords and shields."
Hyper-masculine power fantasy: jacked barbarian-knights slaying fantasy monsters.
Core drive: the **loot & Power grind**. Built in **Godot 4 / GDScript**, milestone
by milestone, each build independently playable.

> This vault is the design source of truth. The code lives alongside it in the same
> repo (Obsidian ignores non-Markdown files).

## The one-line pitch
Kill monsters → get rarity-rolled loot → your **Power** climbs → rebuild your
**home town** with what you gather → chase god-rolls, hunt **Nemesis Warlords**,
and (eventually) run **raids**.
